> 「Android Auto で使えるアプリが少なすぎる…」そんな悩みを解消。**AA Anything** は、**Android 15 以降専用**として最適化され、スマホのルート化不要で、スマホに入っている**幅広いアプリ**（※DRM等の著作権保護やセキュリティ制限が施された一部のアプリを除く）を Android Auto の車載ディスプレイに表示・起動できるようにする画期的なアプリです！

## 💡 主な特徴

- **幅広いアプリに対応（※DRM等の著作権保護やセキュリティ制限が施された一部のアプリを除く）:** スマホに入っている動画や音楽などのアプリを、車載ディスプレイで表示・操作できます。
- **Root化不要:** 端末の改造やパソコンでの作業は不要で、アプリ単体で手軽に設定できます。
- **シームレスな上書き更新:** パッチ適用済みアプリのバージョンアップやシステム更新時の再パッチに手軽に対応。
- **車載画面に合わせた表示:** クルマのディスプレイやタッチ操作でも見やすく扱いやすいレイアウトに対応。
- **標準メディアアプリの無料対応:** VLC などの一般的なメディアプレーヤーは無料でご利用いただけます。

## 🚀 カンタン 3 ステップでスタート！

1. **アプリをダウンロード:**  
   [GitHub Releases (最新リリース)](https://github.com/kododake/AAAnything/releases/latest) から最新の APK をダウンロードしてスマホにインストールします。
2. **Android Auto のデベロッパー設定を有効化:**  
   下記のガイドに従い「提供元不明のアプリ」を有効にします（初回のみ）。
3. **アプリを選んで車で楽しむ:**  
   AA Anything を開いて車で使いたいアプリを選び、「パッチ作成 &amp; インストール」をタップ。あとは車に繋ぐだけで車載画面にアプリが登場します！

## 🛠️ Android Auto で「提供元不明のアプリ」を有効にする手順

パッチを適用したアプリを車載ディスプレイに表示・起動するには、Android Auto のデベロッパー向け設定を解放する必要があります：

1. **Android Auto の設定を開く:** スマートフォンの「設定」アプリで「Android Auto」を検索して開きます。
2. **デベロッパーモードを解除:** 画面の一番下までスクロールし、**「バージョン」の項目を連続で10回タップ**します。表示される確認ポップアップで「OK」をタップします。
3. **デベロッパー向け設定を開く:** 右上の**3点メニュー（⋮）**をタップし、**「デベロッパー向け設定」**を選択します。
4. **提供元不明のアプリを有効化:** 一覧から**「提供元不明のアプリ」**を見つけてチェック（ON）を入れます。
